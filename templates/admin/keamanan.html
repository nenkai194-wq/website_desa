Lapisan Pertahanan Siber Website Desa

Sistem keamanan multi-lapis aktif untuk menjamin kerahasiaan dan integritas data.

Rate Limiting & Anti Brute-Force Otomatis memblokir IP/akun setelah 5 kegagalan login berturut-turut selama 15 menit.
Enkripsi Password Kriptografi Password dienkripsi dengan PBKDF2:SHA256 ber-salt acak. Tidak disimpan dalam plaintext.
Session Hardening & Anti-Fixation Cookie HttpOnly & SameSite=Lax. Sesi di-generate ulang saat login untuk mencegah session hijacking.
HTTP Security Headers Header `X-Frame-Options: SAMEORIGIN` (anti-Clickjacking) & `X-Content-Type-Options: nosniff`.
Prepared SQL Statements Semua query parameterisasi penuh untuk mencegah serangan SQL Injection (SQLi).
Role-Based Access Control (RBAC) Pemisahan 2 level: Super Admin (Sistem & Data) dan Admin (Operasional & Layanan).
