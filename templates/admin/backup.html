Panduan Praktik Terbaik Perlindungan Data Desa

1. Aturan Cadangan 3-2-1

Simpan minimal 3 salinan data (1 aktif di server, 1 cadangan di komputer admin/flashdisk, dan 1 salinan terenkripsi di Google Drive/cloud).

2. Rutinitas Mingguan & Bulanan

Lakukan unduhan database (.db) setiap akhir pekan setelah pelayanan surat selesai, dan unduhan komplit (.zip) setiap akhir bulan.

3. Keamanan File Cadangan

Jangan pernah membagikan file backup kepada pihak luar. File database memuat NIK, nomor WhatsApp, dan data rahasia warga desa.
